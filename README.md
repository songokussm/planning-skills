# planning-skills

A Claude plugin marketplace with one plugin, `planning`: skills for running planning sessions across a folder of projects.

Install: Customize > Plugins > Add marketplace > `songokussm/planning-skills`, then install `planning`.

Update: edit a skill, bump `version` in both `.claude-plugin/marketplace.json` and `plugins/planning/.claude-plugin/plugin.json`, run `scripts/check.sh`, push, then Check for updates in the app.
